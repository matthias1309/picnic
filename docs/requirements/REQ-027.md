# REQ-027 — Close Keyword Rule Gaps Found in the Live Database Review

**Status:** draft
**Created:** 2026-10-10
**Traced by:** _(pending ARCH and TEST)_

## User Story

As the **account owner**,
I want **the categorisation rules to handle the products that were misfiled or
left uncategorised in my live data**,
in order to **have future purchases of the same kind land in the right
category without correcting each one by hand**.

## Context

After REQ-026 a review of the live database (2026-10-10) found products that
the keyword rules in `backend/services/category_service.py` file wrongly or not
at all. All affected live products have already been corrected by hand, so this
REQ changes the rules only: it affects **future** products and the next
`apply_rules` backfill of rule-based products. It does not touch the live
database.

The gaps fall into four groups:

- **Shelf-stable tomato, olive and pickle products** filed as `vegetables`
  because a fresh-food keyword (`tomate`, `gurke`, `knoblauch`) wins.
- **False friends of a general keyword**: `hack` in "Mandeln gehackt", `apfel`
  in a tea, `pflaume` in plum tomatoes, `butter` in "Butter-Chicken", `cola`
  inside "Chocolate", `essig` and `salz` in cleaning products.
- **Products no keyword matches**: Tortelloni, Cup Noodles, Porree, Rohrfrei,
  "E-Block", cat food, and "Taschentücher" (the rule `taschentuch` does not
  match the umlaut form).
- **Spices and seasonings filed as fresh vegetables**: "Paprika edelsüß",
  "Röstzwiebeln".

## Notes

- **Rules only.** No schema change, no new dependency, no new endpoint. The
  live database and production are not touched; any backfill is run by the
  account owner by hand after deploy.
- **Brand keywords** are used only where the product name contains no generic
  word that could match: `meßmer` and `teekanne` (tea-only brands), `purina`
  (pet food only). Everything else uses generic keywords. The per-row
  decisions are documented in ARCH-027.
- **Borderline matches are accepted** and correctable by hand, as in REQ-026
  (e.g. "Oliven in Olivenöl" → condiments, "Spezial Salz" as a food seasoning
  → household). Exceptions are added only if they show up in real receipts.

**Out of Scope:**
- Re-categorising existing products (all already corrected by hand).
- Changing the matching algorithm (still substring, first match wins).
- New categories or UI changes.
- Fresh filled pasta other than Tortelloni (Tortellini, Ravioli) — add when
  they appear in a receipt.
