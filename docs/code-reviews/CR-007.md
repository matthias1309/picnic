# CR-007 — Login Rate Limiting Implementation

**Status:** approved
**Created:** 2026-06-14
**Reviewer:** Claude (Automated Review)
**Traces:** REQ-007
**Covers:** ARCH-007, TEST-007

---

## Summary

Adds a per-username lockout to `POST /picnic/api/auth/login`. A new
`login_attempts` table (`LoginAttempt` model) tracks failed-attempt counts
and an optional `locked_until` timestamp per username. New
`backend/auth/rate_limit.py` exposes `is_locked_out`, `record_failed_attempt`,
and `reset_attempts`, used by `auth_routes.login` to reject login attempts
with `429 Too Many Requests` after 5 failed attempts within 15 minutes, with
a 15-minute lockout.
