### Notes

Beyond the four unit tests, the generated configuration was verified against a
real Apache 2.4 (`/usr/sbin/httpd`, `mod_rewrite`, `AllowOverride All`)
serving the actual `frontend/dist` build:

| Request | Result |
|---|---|
| `/`, `/stats`, `/settings` | 200, `index.html` (AC-023-01) |
| `/assets/index-*.js`, `/assets/index-*.css` | 200, the real asset (AC-023-02) |
| `/picnic-frontend/stats` with `RewriteBase /picnic-frontend/` | 200, `index.html` (AC-023-03) |

The fix only reaches production once the deploy has run **and** Gunicorn has
been restarted by it — note that this particular change lands in the static
document root, so the restart is irrelevant here, but the published
`.htaccess` only appears after a full `scripts/deploy.sh` run, not a bare
`git pull` (see `.claude/rules/learnings.md`, 2026-06-16).
