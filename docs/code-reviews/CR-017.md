## Summary

Adds 12 read-only "Budget for YYYY-MM" boxes below the existing editable current-month box on
the home dashboard, one per preceding month. No backend change: `GET /api/stats/budget?month=`
already accepts an arbitrary month and computes real per-month spend from
`Receipt.effective_date`; `budget_cents` is a global singleton and is simply repeated across all
months (documented limitation, see REQ-017 Notes).

Frontend-only change:
- `frontend/src/lib/format.ts` — new `getPastMonths(n, today)` helper.
- `frontend/src/components/Budget/BudgetStatusCard.tsx` — new presentational component (the
  card markup extracted verbatim from the old `BudgetWidget`, parameterized by an optional
  `action` node and `testId`).
- `frontend/src/components/Budget/BudgetWidget.tsx` — unchanged behavior; now renders
  `BudgetStatusCard` for its non-editing display state instead of inlining the same JSX.
- `frontend/src/components/Budget/BudgetHistory.tsx` — new component, fires 12 parallel
  `/stats/budget` queries via `useQueries` and renders one read-only `BudgetStatusCard` per
  month (`testId="budget-history-card"`, no `action`).
- `frontend/src/pages/Home.tsx` — renders `<BudgetHistory />` below `<BudgetWidget />`.
