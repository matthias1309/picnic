# CR-010 — Filter Ingested Emails by Subject

**Status:** approved
**Created:** 2026-06-15
**Reviewer:** Claude Code
**Traces:** REQ-010
**Covers:** ARCH-010, TEST-010

---

## Summary

Restricts `IMAPClient.fetch_new_emails` to emails whose subject contains a
configurable filter string (default `"Dein Bon"`), using the IMAP
`SEARCH SUBJECT` criterion instead of `SEARCH ALL`. Adds
`Settings.imap_subject_filter` (default `"Dein Bon"`, overridable via
`IMAP_SUBJECT_FILTER` in `.env`), and `poll_emails_task` now passes this
filter through. Non-matching emails are never fetched, never stored as
`Receipt` rows, and remain untouched in the mailbox.
