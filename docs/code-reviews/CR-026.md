## Summary

Splits the `pantry` ("Trockenware") category into six flat sibling
categories (`grains`, `breakfast`, `baking`, `condiments`, `canned`,
`snacks`), keeps `pantry` as "Sonstige Trockenware", and reorders
`CATEGORY_RULES` so every shelf-stable product reaches its specific category.
Adds two invariant tests over the whole rule table (no shadowed rule, no
duplicate keyword).

Files:
- `backend/services/category_service.py` — enum, labels, rule order,
  `categorize()` now casefolds the keyword too
- `frontend/src/types/index.ts`, `frontend/src/lib/chart-theme.ts` — six new
  keys and colours
- Tests: `backend/tests/test_categories.py`, `test_api.py`,
  `test_stats_service.py`, `frontend/tests/Categories.test.tsx`,
  `frontend/tests/ChartTheme.test.ts` (new)

No schema change, no migration, no new endpoint, no new dependency.

## Findings

| # | Severity | File / Line | Description |
|---|----------|-------------|-------------|
| 1 | major (fixed) | `backend/services/category_service.py` `categorize()` | `name.casefold()` turns "ß" into "ss", so a keyword containing "ß" (`grieß`) could never match. Found by TC-026-11; fixed by casefolding the keyword as well. Recorded in ARCH-026. |
| 2 | minor | `frontend/src/lib/chart-theme.ts` | A 20-colour categorical palette fails the dataviz validator (normal-vision floor, CVD separation, chroma). Pre-existing: the 14 REQ-024 colours already fail (`frozen` ↔ `fish` ΔE 5.6). Acceptable because every bar carries its category name on the axis, so identity is never colour-only. Follow-up candidate: single series colour with highlight for the filtered category. |
| 3 | minor | `category_service.py` canned/baking blocks | Borderline matches by design of substring rules: "Maiskolben" → canned (`mais`), "Zuckermais" → baking (`zucker`), "Hefezopf" → baking (`hefe`). Correctable by hand; add exceptions only if they appear in real receipts (ARCH-026 Open Questions). |
| 4 | nit | `category_service.py` condiments block | `öl` still matches inside brand names (e.g. "Kölln" products without a more specific keyword fall into condiments). Mitigated by placing `öl` last; same handling as finding 3. |
