## Summary

Adds a login-protected session for the two household accounts. New `users`
and `sessions` tables back an opaque, httponly `picnic_session` cookie
(30-day expiry). `GET/POST /picnic/api/*` (except `/picnic/api/auth/login`)
now require `Depends(get_current_user)`, applied centrally in
`backend/main.py`. The React SPA gains a `/login` page, a `ProtectedRoute`
wrapper redirecting to it on 401, and a Logout control in the nav.
`backend/scripts/manage_users.py` is a small admin CLI for creating/updating
the two accounts (no self-registration).

### Notes

After merging and deploying, the developer must create the two accounts via:

```bash
python -m backend.scripts.manage_users create <username>
```

run once per account (on the Uberspace host, inside the venv). Until both
accounts exist, no one can log in.
