## Summary

Makes the monthly budget editable from the dashboard. Adds a single-row
`budget_settings` table (`backend/models.py`) and
`backend/services/budget_service.py` (`get_monthly_budget_cents`,
`set_monthly_budget_cents`, falling back to the existing
`MONTHLY_BUDGET_CENTS` `.env` setting when unset). `GET /api/stats/budget`
now reads the persisted value, and a new `PUT /api/settings/budget`
(`BudgetSettingUpdate` / `BudgetSettingOut`, mounted under the existing
authenticated `api_router`) updates it. `BudgetWidget.tsx` gains an inline
"Edit budget" control (input, Save/Cancel) backed by a new
`useUpdateBudget` mutation and `apiClient.putJson`.
