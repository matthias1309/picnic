### Notes

**Verified explicitly during review:**

- No `data-testid`, `role`, `aria` role, or API path required a change —
  which is the AC-020-09 evidence that nothing but text moved. The one
  intentional `aria-label` change (`"Loading"` → `"Lädt"`) is user-facing
  text announced by screen readers, not a selector; TC-020-12 covers it.
- The price-range buttons changed label only; the values stored in
  `useUiStore` are still `3m` / `6m` / `12m` / `all`, so `rangeToFromDate()`
  and `PriceHistoryRange` are untouched. TC-020-06 asserts a `from_date` is
  still sent after clicking "3 Mon.", which would fail if the mapping had
  leaked into the store.
- `formatMonth` uses `Intl` via `toLocaleDateString` rather than a hardcoded
  German month array — no list to drift. TC-020-01 covers the year boundary
  ("2025-12" → "Dezember 2025"), which is the case a naive `new
  Date("2026-08")` + offset implementation gets wrong.
- Repository language rule upheld: identifiers, comments, test names,
  `data-testid` values and these documents remain English per CLAUDE.md. Only
  rendered text is German.

**Follow-ups (not blocking):**

- Finding 3's duplicated budget-card header is a genuine DRY smell. Left for
  REQ-022, which reworks these cards visually and is the natural place to
  collapse the two headers into one component.
