## Summary

Feature: associate each parsed line item with the Picnic order number
(`Bestellnr NNN-NNN-NNNN`) of the section it appears in, and surface it through
the stack so the receipt detail view groups items by order. A single "Dein Bon"
email frequently bundles several orders.

**Scope:**
- `backend/imap/parser.py` — `ParsedItem.order_number`; `_extract_order_number`
  reads the nearest preceding `Bestellnr` header per item row.
- `backend/models.py` — new nullable `ReceiptItem.order_number` column (indexed).
- `backend/services/receipt_service.py` — persist `order_number`.
- `backend/schemas.py` / `backend/api/routes.py` — expose `order_number` in
  `ReceiptItemOut`.
- `frontend/src/types/index.ts` — `ReceiptItemOut.order_number`.
- `frontend/src/components/Receipts/ReceiptDetail.tsx` — group items by order.
- Tests: TC-013-01/02 (parser), TC-013-03 (service), TC-013-04 (API),
  TC-013-05 (frontend).

**Test Results:**
- 90/90 backend tests; 25/25 frontend tests.
- `ruff`, `eslint`, `prettier`, `tsc --noEmit` all clean.
